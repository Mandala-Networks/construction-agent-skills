# Improvement roadmap

## Foundation delivered

- Canonical skills, separate Claude/Codex manifests, synchronized versions.
- Four generic role definitions with bounded draft responsibilities.
- Three operational review skills and synthetic acceptance scenarios.
- Local package checks and a conservative sensitive-content heuristic.

## Next evidence gates

| Area | Next deliverable | Completion evidence |
| --- | --- | --- |
| Bid review | Broader conflicting-addenda and proposal benchmarks | Blind model comparison with source and abstention scoring |
| Drawing revisions | Synthetic vector/raster issue pairs | Coverage and change localization scored separately |
| Document control | Extraction/readiness cases across OCR and permissions | No false-ready decisions on withheld or unreadable pages |
| Commercial workflows | Generic RFI, submittal, change, and payment skills | Authored or licensed sources; arithmetic and decision-boundary cases |
| Agents | Read-only consumer integration | Replay, revocation, concurrency, and budget tests |
| Platforms | Isolated native install tests | Same fixture succeeds in each advertised runtime |
| Distribution | Owner-selected license and release policy | License file, attribution, tagged version and tested archive |

Avoid expanding the catalog with untested copies. Bring reusable behavior from
consumer work upstream only after rewriting it around synthetic examples and
removing organization details. Keep deployment crosswalks in the consuming repo.
Do not infer performance from an example answer that passes its own scorer.
