# Drawing revision change log

Compare an explicitly identified earlier drawing issue with a later issue.
Normalize sheet numbers and revision identifiers before comparison. Report
visible additions, removals, relocations, quantity changes, and note changes
with sheet and detail references.

Never claim that a visual difference changes contract scope without human
review. Separate unreadable, missing, or non-comparable sheets from unchanged
sheets. The output must include comparison coverage, potential changes,
uncertainties, and sheets requiring manual review.

This specification is not benchmark-ready until synthetic vector and raster
drawing fixtures are added.
