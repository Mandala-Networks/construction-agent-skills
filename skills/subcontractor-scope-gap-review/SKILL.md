# Subcontractor scope gap review

Build a sourced crosswalk between bid requirements and a subcontractor
proposal. Classify each requirement as included, excluded, qualified, unclear,
or not addressed. Cite both the requirement and proposal locations.

Do not convert silence into an exclusion, normalize unlike allowances as equal,
or recommend an award. Flag commercial, safety, schedule, and legal decisions
for a named reviewer. Keep alternates, unit prices, allowances, and exclusions
as separate concepts.

This specification is not benchmark-ready until synthetic proposal and bid
package fixtures are added.
